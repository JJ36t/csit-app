# لوحة التحكم — React + Vite + Ant Design

واجهة الإدارة (الطلاب، الجداول، الإعلانات، الدرجات، المستخدمون، سجل التدقيق) بواجهة عربية RTL.

## التشغيل

```bash
npm install
npm run dev      # التطوير على http://localhost:5173
npm run build    # بناء إنتاجي في dist/
```

## حالة التحقق

- `npm run build` (tsc + vite) **مُنفَّذ ونجح** في بيئة الإعداد — انظر README الرئيسي للمستودع.
